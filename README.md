# KnowledgeFlow Android APK

เว็บแอปเพื่อการเรียนรู้แบบโหนดเชื่อมโยงและจำลองการไหล ถูกบรรจุใน Android WebView เพื่อ Build เป็น APK

## ฟีเจอร์ที่มีในต้นแบบ
- ลากโหนด, เลื่อน canvas, ซูมด้วยล้อเมาส์/ทัชแพด
- แตะโหนดเพื่อดูรายละเอียดและแก้ไขชื่อ/คำอธิบาย/รูปภาพ URL/อ้างอิง
- ลบโหนด, เพิ่มโหนด
- เส้นเชื่อมพร้อมอนุภาคแอนิเมชันเปิด/ปิดได้
- สูตรผสมตัวอย่าง: อะตอม + อะตอม = โมเลกุล, เซลล์ + เซลล์ = เนื้อเยื่อ
- Codex, ส่งออก/นำเข้า JSON
- JSON Schema อยู่ที่ `schema/knowledgeflow.schema.json`

## Build APK ฟรีจากแท็บเล็ตผ่าน GitHub Actions
1. สร้าง GitHub account แล้วสร้าง repository ใหม่ชื่อ `KnowledgeFlow`
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดใน ZIP นี้ไปยัง root ของ repository (ต้องรักษาโครงสร้างโฟลเดอร์)
3. ไปที่แท็บ **Actions** และเปิดใช้งาน Actions หาก GitHub ถาม
4. เลือก workflow **Build KnowledgeFlow APK** แล้วกด **Run workflow** หรือ push ไฟล์ขึ้น branch `main`
5. เมื่อ workflow สำเร็จ เปิด run นั้น แล้วดาวน์โหลด Artifact ชื่อ `knowledgeflow-debug-apk`
6. แตก ZIP ที่ดาวน์โหลด จะได้ `app-debug.apk`
7. แตะ APK บน Android เพื่อติดตั้ง หากระบบถาม ให้เปิดอนุญาตติดตั้งแอปจากแหล่งที่ใช้ดาวน์โหลด

## หมายเหตุ
- Workflow ใช้ GitHub-hosted runner และ GitHub Actions quota/ข้อกำหนดฟรีอาจเปลี่ยนแปลงได้
- APK ที่ได้เป็น debug build สำหรับทดลองใช้ ไม่ใช่ release ที่เซ็นชื่อเพื่อเผยแพร่ในร้านแอป
- แอปต้นแบบเก็บข้อมูลไว้ในหน่วยความจำของหน้าเว็บเป็นหลัก: ส่งออก JSON เป็นระยะเพื่อสำรองข้อมูล การแก้ไขข้อมูลอาจหายเมื่อปิดแอป/โหลดใหม่
- รูปภาพภายนอกต้องใช้ URL ที่เข้าถึงได้ และบาง URL อาจไม่อนุญาตให้ฝังภาพ
- ตัวอย่างเนื้อหาชีววิทยาเพื่อการเรียนรู้ ไม่ใช่การจำลองทางการแพทย์เชิงปริมาณ
